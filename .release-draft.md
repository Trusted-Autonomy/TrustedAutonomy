## v0.17.12-alpha.11

### New Features
- Persistent per-user key custody: `ta credentials custody status|file|keychain`. Developer installs default to file custody, ending the endless macOS Keychain prompts on rebuilt binaries.
- One state-directory resolver with `ta state show|relocate`, a verified one-time migration and a `ta doctor` check.
- Model tier and reasoning-effort profiles: `ta run --profile`, `--tier`, `--effort`, mapped per agent framework (Claude Code, Codex, Gemini CLI, Antigravity, Ollama) from a shipped catalog with project/user overrides.
- OS sandbox work: macOS Seatbelt v2 with an egress proxy, Linux bubblewrap/Landlock/seccomp, Windows AppContainer parity, default-on isolation for Chief-of-Staff and team roles.
- Cost tracking: goal spend and origin class, `ta cost report` across goals and interactive sessions, output-token split, per-goal export and Meridian export.
- Chief-of-Staff chat mode: secure launch primitive, read-only persona tool surface, Wayfinder read tools, task intake funnel, goal/KPI proposals.
- Atomic apply, rules engine with security postures, VCS detection and `ta setup vcs`.
- Golden-set capture and replay, swappable optimizer slots (RTK optimizer), one `ta cleanup` engine, automatic pruning of merged branches and worktrees, shared build cache for goal agents.
- Wake-on-demand listeners with persistent agent ids, `ta credentials update`, Wayfinder wiki MCP tools.
- `blocked` plan phase status.

### Improvements
- `ta doctor` now checks key custody, the state directory, a daemon started without an agent login, and committable `*.cred` files.
- Every keychain wait is bounded; `ta cost report --rows` is faster.
- Daemon exposes project identity on every response and `.ta/daemon.json` as its address record.
- Automatic version sync and nightly version stamping.

### Bug Fixes
- A missing vault key no longer silently generates a replacement key; secret directories are created `0700`; the sandbox denies `~/.config/ta/human`.
- Fixed Windows failures in state-directory migration and Windows CI process leaks.
- Fixed draft apply fidelity (plan merge touches only the target phase) and an apply after an interrupted apply committing a half-bumped version.
- Fixed Discord channel access control on commands, draft buttons and goal input; wiki writes now go through draft review.
- Tests can no longer reach paid external agents.

### Known limitations
- macOS binaries are not Apple-notarized and Windows binaries are not code-signed yet (phase v0.17.12.12 is blocked). Release checksums are Sigstore-signed; verify them before running.
- Real Keychain, launchd, Linux and Windows end-to-end flows are covered by tests and CI but have not been proven in real-world use.
- Model/effort mapping correctness for Codex, Gemini and Ollama is a pending phase (v0.17.12.33); check the logged `agent= tier= effort= model=` line for what was applied.
- `ta run --phases` and `--sub-goals` ignore `--profile`, `--tier`, `--effort` and `--model` (a warning is printed).
