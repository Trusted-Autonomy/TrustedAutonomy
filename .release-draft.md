## v0.17.11-alpha.7

### New Features
- Agent Coordination Whiteboard — agents working on the same goal can see each other's presence, claim tasks, and hand off work in real time.
- Wayfinder-backed plan storage — plan phases can optionally sync to Wayfinder as an external status mirror.
- Staged-resource conflict detection — TA now flags when two in-flight goals stage conflicting changes to the same resource.
- Virtual-team model tiers and local tags on team members, for cost/capability-aware agent routing.
- One-command project onboarding via `ta init`.
- Advisor natural-language multi-phase entry point — describe multi-phase work in plain language and have the Advisor plan it.
- Multi-role review panels with a single, unified approval gate.
- Workflow graph engine with new step types (`agent_review`, `pr_monitor`, `plan_check`, `sync_build`) for custom pipelines.
- Least-privilege credential system: Biscuit session tokens, enforced credential scopes, live token issuance with encryption at rest, human escalation for scope elevation, and cryptographic attenuation for swarm fan-out.
- Release artifacts are now signed (Sigstore/cosign, keyless).
- Pluggable domain-action adapters for user-authored plugins, plus workflow-defined budget guardrails.
- Persistent team session runtime.
- `ta release` core command with built-in release adapters.
- Safe parallel/sequential phase execution based on dependency waves.
- Meridian KPI regression detection with plan-phase alignment suggestions, plus token tracking for `ta meridian` reports.
- Build-milestone automation triggered by VCS status.
- Community tools now available directly in `ta serve`'s MCP gateway.
- Studio redesign with a new Smart Advisor and richer draft review details.
- Managed paths: content-addressed filesystem plus a URI journal for tracking staged changes.
- Generic prompt-optimizer plugin system.
- Headroom: automatic context compression for Claude agents.
- Connector Supervisor for fault-isolated plugin processes.
- Agent-switching and a 3-tier routing overhaul (trigger / brain / back-office).
- Virtual team roles with structured Advisor context.
- New `ta plan reset <phase-id>` command.

### Improvements
- More reliable daemon restarts (graceful session drain, shutdown handling, adaptive timeouts, heartbeat).
- Draft rebuild window widened to allow rebuilding from `pr_ready`/`approved` states.
- VCS-adapter CI-status handling generalized, with corrective goals triggered automatically on failure.
- Various Studio UI cleanups and dashboard responsiveness fixes.
- Doctor log hygiene, Advisor progress visibility, and onboarding gap fixes.
- More reliable version bumping and nightly releases.
- Decision-gate, consensus-panel, and dependency-wave planning logic extracted into standalone open-source crates.

### Bug Fixes
- Hardened daemon authentication and transport trust boundaries.
- Fixed a credential (DSN) leak in DB proxy capture logs.
- Fixed three bugs blocking custom local-model agent frameworks; the Ollama agent no longer treats "summarized instead of acted" as done.
- Fixed an unsafe early-write in plan-patch application and related stale-staging-vs-concurrent-main apply bugs (ghost deletions, checkbox reversion).
- Fixed staging isolation for concurrently running goals.
- Fixed `ta draft close` leaving goals in a non-terminal state.
- Fixed `ta setup vcs --force` silently dropping unregistered gitignore entries.
- Fixed supervisor review being fed stale or unrelated file lists.
- Fixed a panic in `ta list goal` on multi-byte title truncation.
- Fixed an Advisor autonomous-loop hang by migrating to confidence-gated human verification.
- Fixed an advisor-review subprocess colliding with its parent goal's phase claim.
- Fixed wrong draft-storage paths used by `ta plan build --autonomous` and goal recovery.
- Fixed installer Nix PATH probing after reboot and the MSI license file path.
- Fixed MCP approval dialogs incorrectly appearing during interactive and headless agent runs.
- Fixed daemon reachability checks and status timeouts.
